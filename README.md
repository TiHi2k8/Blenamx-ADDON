# Blenamx ADDON

Blenamx is a Blender addon designed to simplify and improve the creation of content for the DynamX Minecraft mod.

It provides tools for creating, configuring and preparing DynamX-related content directly within Blender.

## Features

- Vehicle creation and configuration
- Vehicle parts and components
- Seat setup
- Hitbox creation
- Wheel configuration
- Clothing support
- Block creation
- Pack creation and management
- Workspace and scene organization
- Export and preparation tools
- Blender-based workflow for DynamX content

## Requirements

- Blender 5.2 or compatible version
- DynamX knowledge may be required for advanced features

## Installation

1. Download the latest **Blenamx ADDON** release from the GitHub Releases page.
2. Open Blender and go to:
   `Edit > Preferences > Add-ons`
3. Select **Install...**
4. Select the downloaded Blenamx `.zip` file.
5. Enable **Blenamx ADDON** if needed.

## Usage

After installation, Blenamx provides additional tools and operators inside Blender for creating and preparing DynamX content.

The addon is intended to make the creation process easier by providing dedicated tools instead of requiring every configuration step to be performed manually.
